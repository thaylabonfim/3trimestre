# Site pessoal - Thayla Amaral

Trabalho do 3º trimestre da turma de Desenvolvimento de Sistemas.

## Páginas

- `index.html` – página inicial com o banner e os cards dos amigos
- `sobre.html` – apresentação, projetos e objetivos
- `contato.html` – formas de contato
- `jogo.html` – jogo da memória feito com JavaScript
- `certificados.html` – espaço dos certificados do curso

## Arquivos

- `style.css` – estilos de todas as páginas
- `menu.js` – abre e fecha o menu hambúrguer
- `jogo.js` – lógica do jogo da memória
